## 🚀 What this app does

comfyui-workflow-skill turns plain English into ComfyUI workflow JSON.  
It helps you create ready-to-use workflows for image, video, audio, 3D, and LLM tasks without building each flow by hand.

It includes:

- 34 built-in templates
- 360+ node definitions
- Auto model download
- Support for many ComfyUI setups
- Skill support for Claude Code, Cursor, and other AI agents

Use it to build workflows for:

- txt2img
- img2img
- txt2vid
- img2vid
- audio
- 3D generation

It supports common model families like:

- SD1.5
- SDXL
- SD3
- FLUX
- Wan2.2
- HunyuanVideo
- LTXV
- Mochi
- Cosmos

## 🔍 Troubleshooting

### The ZIP does not open

Try downloading it again from the GitHub page.

Then extract it with Windows Extract All.

### The folder looks empty

Check that you extracted the ZIP, not only opened it.

Look inside the extracted folder for the project files.

### ComfyUI does not load the workflow

Make sure the JSON file saved correctly.

Check that the workflow matches the version of ComfyUI you use.

### Models are missing

Run the auto download step if your setup supports it.

If needed, place the models in the folder expected by ComfyUI.

### The AI tool does not find the skill

Check the project path and make sure the tool can read the folder.

Then restart the tool and try again with a clear prompt.
